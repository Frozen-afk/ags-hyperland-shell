# AGS v2 + Astal Desktop Shell — "Astral" for Hyprland / Fedora

A complete, glassy GTK4 desktop shell (bar, dock, launcher with plugins,
clipboard manager, notification popups **+ notification center**, window
switcher, power menu, screenshot menu, quick settings control center,
wallpaper picker with live re-theming, system vitals, screen recorder HUD,
OSD, draw-mode indicator) built with **AGS v2**, **Astal**, TypeScript/TSX.

The palette is fully themable: `theme/colors.css` holds every color and is
regenerated by **matugen** from whatever wallpaper you apply — the whole
shell re-colors itself live.

## 1. Fedora installation

```bash
# --- Core Wayland compositor + AGS/Astal toolchain -----------------------
sudo dnf install -y hyprland hyprland-devel xdg-desktop-portal-hyprland \
    gtk4 gtk4-devel gjs gjs-devel gobject-introspection-devel \
    NetworkManager-libnm bluez glib2-devel

# AGS v2 ships as a Fedora COPR build; astal libraries come from the
# COPR repo maintained by the Astal project.
sudo dnf copr enable solopasha/hyprland -y
sudo dnf copr enable atim/aylurs-gtk-shell -y      # ags v2 build for Fedora
sudo dnf install -y aylurs-gtk-shell

# Astal core + widget libraries (gir bindings consumed via gi://Astal*)
sudo dnf copr enable atim/astal -y
sudo dnf install -y astal-io astal-gtk4 \
    astal-hyprland astal-apps astal-tray astal-notifd \
    astal-wireplumber astal-network astal-bluetooth \
    astal-battery astal-mpris astal-powerprofiles

# Node/TypeScript toolchain (AGS compiles TSX via esbuild under the hood)
sudo dnf install -y nodejs npm

# --- CLI utilities the widgets shell out to --------------------------------
sudo dnf install -y grim slurp swappy wl-clipboard cliphist \
    brightnessctl playerctl jq wf-recorder libnotify

# gromit-mpx (annotation overlay) — Fedora main repo
sudo dnf install -y gromit-mpx

# supergfxctl (hybrid GPU switching, ASUS/Optimus laptops) — COPR
sudo dnf copr enable lukenukem/asus-linux -y
sudo dnf install -y supergfxctl

# power-profiles-daemon (used by AstalPowerProfiles), usually preinstalled
sudo dnf install -y power-profiles-daemon
sudo systemctl enable --now power-profiles-daemon

# hyprlock + hypridle for the lock screen and idle management
sudo dnf install -y hyprlock hypridle

# --- Wallpaper picker + dynamic theming + night light ----------------------
sudo dnf copr enable tofik/hyprland -y
sudo dnf install -y swww hyprshade

# matugen drives the dynamic theming (optional but the whole point)
cargo install matugen
# or: download a prebuilt binary from https://github.com/InioX/matugen/releases
```

Optional extras referenced by widgets (they render nothing when missing):
`supergfxctl`, `gromit-mpx`, `hyprshade`, `wf-recorder`, `matugen`.

## 2. Install + deploy

**Everything at once (needs sudo, fully reversible):**

```bash
cd ags
sudo ./install-fedora.sh
```

This enables the `sachesi/hyprland` COPR (Hyprland 0.56 + lock/idle/portal),
installs the CLI tools and build dependencies, builds **ags v2.3.0 + the
astal libraries (pinned rev)** into a self-contained `/opt/astral/` (the
official repos only ship ags v3, which is incompatible), installs the local
`rpms/` (swww, matugen, appmenu-glib-translator), deploys configs via
`install.sh` and verifies everything.

**Remove it all again in one shot:**

```bash
sudo ./uninstall-astral.sh
```

Packages are `dnf remove`d + autoremoved, the COPR is disabled,
`/opt/astral`, the shim and deployed configs are deleted (config files you
modified yourself are kept).

**Already have the packages?** Just deploy the shell:

```bash
cd ags
./install.sh        # copies shell to ~/.config/ags + hypr configs
hyprctl reload
```

`install.sh` copies the shell to `~/.config/ags/` (including `theme/`),
deploys the Hyprland snippet as `~/.config/hypr/shell.conf`, installs
`hypr/hyprland.conf` if you don't have one yet (edit the `monitor` line for
your setup), and never overwrites existing `hyprlock.conf`/`hypridle.conf`.

## 3. Run standalone (for iteration/debugging)

```bash
ags run ~/.config/ags/app.ts
```

AGS auto-restarts on file changes when run this way; for production the
`exec-once = ags run ~/.config/ags/app.ts` line in the Hyprland config
launches it with the compositor.

### Typechecking locally

The real Astal GIR types are generated by AGS on the user's machine and are
not published to npm, so this repo vendors the exact astal JS glue AGS v2.3.0
runs (`vendor/astal`) plus hand-written GIR stubs (`types/`). That makes

```bash
npm install        # typescript + @girs/gtk-4.0 etc.
npm run typecheck  # tsc --noEmit
```

work without Hyprland/AGS installed. If you change vendor patches, re-read
the "vendored patches" section below.

## 6. Theming

- `theme/colors.css` defines GTK named colors (`@define-color accent …`),
  imported at the top of `style.css`; edit it to retint everything.
- Applying a wallpaper runs `matugen image <wallpaper> --mode dark
  --config ~/.config/ags/theme/matugen-config.toml`, which regenerates
  `~/.config/ags/theme/colors.css` from `theme/colors.css.template` and the shell
  hot-reloads its CSS (`App.apply_css(path, true)`).
- Without matugen, the default Tokyonight-inspired palette stays.

## 7. Vendored patches (vendor/astal)

The runtime glue (`vendor/astal`, pinned to the astal rev AGS v2.3.0 pairs
with) carries small patches, kept minimal and documented inline:

- `Icon` widget (`Gtk.Image` accepting icon name / GIcon / file path — the
  GTK4 Astal core has no `Astal.Icon`), `Scrollable`, `Picture` widgets and
  their JSX intrinsics.
- `$type` prop support (alias of the astal child-type prop).
- Slider gained `onValueChanged` (fires on pointer drags too, unlike
  `onChangeValue`/`change-value`).
- JSX `Element` accepts `Binding<Widget>` (the runtime already unwraps it).
- `mkApp` typed for the GTK4 app only, so `App.get_window`/`apply_css` typecheck.

## 8. Notes & assumptions

- Layer rules target each window's `name` (Astal maps it to the layer
  namespace): `bar-0`, `launcher`, `notifcenter`, `switcher`, … — see
  `hypr-snippet.conf`.
- `SystemIndicators.tsx`'s caps-lock check shells out to `hyprctl devices -j`
  since GTK4 doesn't expose keyboard LED state on Wayland.
- `GpuModeIndicator`, `DrawToggle`, night light, brightness and recorder all
  no-op gracefully when their binaries are missing.
- Shell plugin (`>command`) runs with your shell and closes the launcher;
  calculator results are copied to the clipboard with Enter.
- Notification history survives popup timeouts: closing a popup keeps the
  entry unread in the center; dismissing there clears the badge.
